# CL Catalog / PIM

Каталог анализов Centrālā Laboratorija: замена Excel-файла `Laboratorija_Pricelist_SSoT` на SharePoint отдельным приложением. SmartLIS остаётся источником правды, приложение — инструмент редактирования, публикации на сайт и отправки правок обратно в SmartLIS.

Статус на 17.11.2026: рабочий прототип в пилоте (UAT), боевое приложение ещё не начато. Интеграция со SmartComm API описана, API выходит в PROD на неделе с 22.11.2026.

## Что в репозитории

| Папка | Что это |
| --- | --- |
| `prototype/` | Прототип: одна HTML-страница (`index.html`) и вся логика синхронизации в `logic.js` без DOM. Пример данных — `seed.sample.json` |
| `prototype/tests/` | Тесты логики (`node:test`), работают на синтетическом примере |
| `office-scripts/` | Исправленные Office Scripts для текущего Excel-файла и инструкция по установке |
| `docs/` | Ссылки на требования, спецификацию интеграции и план пилота; заметки по SmartComm API |

## Быстрый старт

```bash
npm test          # 15 тестов логики, нужен Node.js 20+
npm run serve     # прототип на http://localhost:8080 с примером данных
```

Локально прототип работает без хранилища: правки живут до перезагрузки страницы. Общие данные, роли и журнал работают в опубликованной версии прототипа на claude.ai (ссылка у владельца проекта).

## Главное в логике (`prototype/logic.js`)

- **Реестр полей** (`DEFAULT_FIELDS`): у каждого поля источник (SmartLIS или каталог), кто может править (`e`: none / business / marketing / admin), участие в выгрузке на сайт. Список полей SmartLIS меняется — новое поле добавляется записью в реестре.
- **Роли** (`ROLES`, `ACTIONS`, `canEditWith`, `canDoWith`) — группы AD: администраторы (DPT CLA ITD Admins) могут всё; бизнес (DPT CLA Administracija) — поля SmartLIS и цены, `publish`/AKC, Veterinary, импорт и отправка в SmartLIS; маркетинг (DPT CLA Marketinga nodala) — тексты сайта LV/RU/EN, SEO, изображения, Web JSON. Несколько групп — сумма прав. В прототипе роль выбирается в меню (в пределах уровня Share), в боевой версии её определяют группы, а права проверяет сервер.
- **Цены** (`priceChanges`): любое изменение — предупреждение со списком «было → стало» и повторный запрос (ввести код или число тестов); массовая правка — не больше `priceBulkMax` (50) тестов; каждое изменение — событие «цены» в журнале с именем и ролью.
- **Импорт** (`planImport`): поле, которое в каталоге не правили, просто берёт значение SmartLIS. Отредактированное поле сверяется по трём значениям (`base` — последняя синхронизация, `val` — каталог, SmartLIS сейчас); изменение с обеих сторон — конфликт, ничего не перезаписывается. Защиты: не UTF-8, дубли кодов, неполная выгрузка, массовая очистка поля (съехавшие колонки), склеенный `govcode`. Импортируются только `active = TRUE`.
- **Отправка** (`planExport`): только правки, которых ещё нет в SmartLIS; пустое обязательное поле блокирует отправку; массовое изменение требует подтверждения. Правка закрывается, когда импорт показывает то же значение в SmartLIS.
- **Сайт** (`buildWebJson`): тесты с `publish = TRUE`, из цен только `fin_price2`; акции AKC — отдельный массив `promotions` с `fin_cost1`, по умолчанию выключен. Тексты на LV, RU и EN (`…_ru`, `…_en`) и ссылки на изображения `media1–3` (с версии SSoT от 24.11.2026).
- **Перенос из Excel** (`buildFromExcel`): поля каталога берутся из колонок с тем же техническим именем (вторая строка листа Catalog), новые колонки подхватываются без доработки. При дубле кода берётся строка, где заполнено больше полей каталога. Реестр, сохранённый в базе, дополняется новыми полями по умолчанию (`mergeFields`).
- **Таблица каталога** (`matchCol`, `compareBy`): сортировка и фильтр в каждой колонке (текст — вхождение, `!слово`, `=` пусто, `!=` заполнено; числа — `>5`, `3–10`; списки — выбор значения); набор колонок настраивается и запоминается в браузере.

Решения, на которых это построено: `code` неизменяем; тесты создаются только в SmartLIS; приложение ничего не удаляет; все вызовы SmartLIS — от технического пользователя с сервера приложения.

## Данные

Реальный каталог, выгрузки SmartLIS и исходный Excel в репозиторий не кладутся (`.gitignore`): в них себестоимость и цены по старым договорам, а в Excel — метаданные сотрудников. `seed.sample.json` — 30 настоящих кодов и названий тестов со случайными ценами.

Чтобы запустить прототип на реальных данных локально, положите снимок в `prototype/seed.json` (формат как у `seed.sample.json`); он в `.gitignore`.
